# Dashboard

The touchscreen page shown fullscreen by Chromium on the Pi (1280 × 720, the Touch Display 2 in landscape). It reads JSON only from the console service on the same Pi; the service decides freshness and ranks the alerts (`docs/contracts.md`), and this page turns that into words and colours.

| File | What it is |
|---|---|
| `common.js` | Shared by every screen: the status bar (the main clock, UTC or local, with the other beside it, mode, callsign · grid, Internet/NAS/GPS), the module row with the Alerts badge, the clock, the one freshness function, and polling the service every 15 s. On a detail page it goes back to Home after 3 minutes untouched, or at once for a new unacknowledged critical item. Also the toolbar's Refresh (shows "Refreshing…" then "Updated"), Sleep (backlight off behind a black cover; the first touch only wakes) and the Shut down dialog (Cancel, Restart, Shut down) |
| `home.css` | Fonts, colours and the shared layout (status bar, module row, tiles, toolbar), plus the Home screen's own styles. Every screen loads it |
| `index.html`, `home.js` | The **Home screen**, built from the approved mockup: the Priority Card (‹ › paging, 60-second rotation unless a critical item pins it, flashing border and Acknowledge for critical items, two-step Clear hold for lightning), and the Propagation, Weather and System tiles |
| `weather.html`, `weather.css`, `weather.js` | The **Weather page** (`/weather`), from the approved mockup: this location's lightning and NWS alerts, current conditions (the home Tempest in Home Mode), the NOAA Weather Radio panel, four forecast periods and the next 12 hours |
| `propagation.html`, `propagation.css`, `propagation.js` | The **Propagation page** (`/propagation`), from the approved mockup: the ten bands as good → fair → poor (in the order the service sends), "Best now", and the solar and geomagnetic figures in words (K index on NOAA's G scale, X-ray on the R blackout scale), amber at the same "disturbed" thresholds the alert list uses. The MUF map button is "Coming" |
| `alerts.html`, `alerts.css`, `alerts.js` | The **Alerts page** (`/alerts`), from the approved mockup: what is on the Priority Card (worst first, with Acknowledge on critical items), the less urgent notifications counted on the Alerts badge ("new" until shown once), and NWS alerts that ended in the last 24 hours. Details opens the full NWS text and instruction; lightning items have the two-tap Clear hold. Every label is a word as well as a colour |
| `system.html`, `system.css`, `system.js` | The **System page** (`/system`), from the approved mockup: this Pi (temperature, load, memory, disk, power, uptime, version), network, location and clocks (Wi-Fi signal, internet, GPS, NTP, the RTC backup battery), and each data source's freshness |
| `settings.html`, `settings.css`, `settings.js` | The **Settings screen** (`/settings`), in the tabs approved on 5 November 2026: Station & profile (callsign and grid), Display (main clock, brightness, night style and times), Data sources (addresses, Test connections, weather radio list age and Update now) and Wi-Fi (current network). Every change is saved on the Pi at once, through `PUT /api/settings`; text is typed on the on-screen keyboard. Parts for later phases are shown dimmed and marked |
| `fonts/` | Barlow and Barlow Condensed, bundled so the screen looks the same in the field with no internet. SIL Open Font License (`fonts/OFL.txt`) |
| `check.html` | The plain service check page, served at `/check`, for diagnostics |

**Not built yet:** the MUF map screen and Help. The Field Day timer (12 November 2026) is `renderFieldDayPill` in `common.js`, set on the Settings Station & profile tab. The Red night style (12 November 2026) is in `common.js` (`syncNightStyle`) and `home.css` (`html.night-red`). Sleep, screen brightness and Shut down need two small permission rules on the Pi (`pi/udev/`, `pi/polkit/`, see `pi/README.md`); without them the screen says what's missing. Their buttons are in place, dimmed and marked "Coming". The Weather page's NOAA Weather Radio panel says "Station list not loaded yet" until the service has downloaded the NWS transmitter list once (it then works offline), and shows in amber when the transmitter isn't confirmed for the county.

Display rules from the approved design: stale data loses its colour and shows "STALE · N MIN"; unavailable NWS alerts never read as "no alerts"; every colour comes with a word.
